# Weekly Digest UI kit

A click-through recreation of the Weekly Digest edition view, composed from the system's components (SiteHeader, Tabs, StoryTile, QuoteTile, Pill, Hashtags, Thumbs). All content is sample.

- Primary tabs switch selection; NEWS sub-tabs open and select their section.
- Each NEWS section is a disclosure: click the heading to open or collapse it.
- Thumbs down on a story opens the reason box.

The production template, with every slot, page state and the PREDICTION / HOMEWORK / ARCHIVE panels, is `Weekly Digest Template.dc.html` at the project root; its slot list is `Weekly Digest Slots.md`.
