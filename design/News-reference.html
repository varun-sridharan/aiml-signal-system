AIDO THISKNOW
MCP's 2026-07-28 spec moves the core from stateful to stateless request/response

Why it matters: Stateless lets you scale MCP servers horizontally behind a plain load balancer — no sticky sessions, no shared session store. Cost: it breaks cross-version compatibility, and Roots / Sampling / Logging + Dynamic Client Registration are now deprecated (12-month runway).

Example: today a stateful server needs sticky sessions — if your 2nd call lands on a different node than your 1st, the session context is gone and the call fails. Stateless means any node can answer any request.

↔ Ties to the thread: this is the "harness > model" shift made concrete — as models converge, infrastructure like MCP is where differentiation moves.
