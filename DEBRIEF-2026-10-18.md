## 7. Open review findings

Not fixed, by design or by scope (each reviewed and accepted):
- A failed `gates` stage cannot self-heal inside a week: it retries the same checkpointed framing at temperature 0 and fails the same way. A human decides; the run id is the week key and a done stage is immutable.
- Every item is `category: "AI"` because all nine feeds are AI sources, so the gates "DO THIS only on AI" and "examples only on AI" are vacuous until other categories have sources.
- `reader.http_get` parses feeds with the standard-library XML parser (expat's own entity limits, 3 MB read cap); `defusedxml` would be stricter.
- Rate limits (`/add-news`, votes) are per process or per client hash, not global.
- TRUNCATE bypasses row-level append-only triggers (as it does for runs and excerpts); only the table owner can run it.
