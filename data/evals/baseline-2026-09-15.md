**Two stable modes, 3 vs 2.**

- Runs 1–3 — the miss. The grader enumerated the *source's* wording (`"Anthropic is valued at $965B"`) rather than the writing's (`"Anthropic raised $965B"`). Everything supported, confidence 1.0. The distortion was never examined because the sentence containing it was never picked up.
- Runs 4–5 — the catch. It read the writing and flagged the plant, but then marked `"Anthropic's $965B valuation"` in the thread unsupported *while quoting the exact span that supports it*. The harness does not count "real span but unsupported" as a grader error, so it surfaces as a plain false positive.

Catch rate 2/5. With n=5 the true rate lies somewhere around 10–75%; 40% is a point estimate, not a measurement.

## What was ruled out

| Hypothesis | Verdict | Evidence |
|---|---|---|
| Model drift | No | One Haiku 4.5 snapshot exists; the alias never moved. Cost $0.00 to check. |
| Sampling noise | No | 2026-08-04 byte-identical 5/5 at `temperature=0`. |
| Wrong inputs to the grader | No | `framing = framing_from_framed_day(case["output"])`; `check_faithfulness(client, case["input"], framing)`. Confirmed behaviourally: runs 4–5 flagged `"raised $965B"`, a string that exists only in `output.json`. |
| Wrong labels | No | Every flag matches a category the grader's own prompt excludes. |

An earlier reading of the 2026-08-19 ledger — ten calls at `input_tokens=4715` with outputs spanning 1390–1895 — was taken as evidence that `temperature=0` is non-deterministic. It is more likely ten *different* payload arrangements during the Phase 3 reordering work: reordering preserves token count exactly. Today's data shows determinism holding on one input and not on another, which is a different and narrower claim.

## The diagnosis

Both failures are **selection**, before any judging:

- **Too strict** — grades sentences that are not factual claims. The verdict ("no evidence") is correct and meaningless, because no evidence could exist.
- **Too lenient** — grades sentences from the wrong document. The verdict ("supported") is correct and meaningless, because the source agrees with itself.

A grader enumerating only the writing's factual sentences produces neither.

## Success criteria for the fix

- `2026-08-04`: false positives near zero, at N=3.
- `negative-01`: the plant caught 3 of 3.
- Anything less and the fix is not the fix.
