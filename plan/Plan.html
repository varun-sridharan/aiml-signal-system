Build Plan — AI/ML Signal System

Rolling, session-sized. Each phase is timeboxed to ~1 hour. Design detail lives in System-Design.html.

How this plan works

• Rolling: the next few phases are detailed; later ones are outlined and filled in as we reach them.

• 1-hour phases: each phase has an end state and fits one working session.

• Milestone activities: each says what it accomplishes and why; the how lives in a canonical prompt under prompts/ (final & holistic — see the folder README).

• Notes = decision log: Claude maintains the decisions, tradeoffs, and priorities per phase from our sessions, and updates them when a phase concludes.

• Knowledge Hub ritual: after every session, Claude also updates the concepts reference at Personal/Knowledge Hub/AI-ML-Concepts.html with any AI/ML or agentic concepts we covered.

NOTES — decisions / tradeoffs
  • Eval harness lives in the repo from early on; the Tuner-driven learning matures later (needs weeks of data).
  • Held-out slice kept separate from anything the Tuner adapts on (train/test hygiene).
  • First golden-set case comes free: the Phase 2 grader false positive. Fix the check to (a) not miss clauses and (b) grade the thread against the union of all item excerpts, not one item's.
  • Done 2026-08-19 (Opus 5): run_evals.py runs three checks — faithfulness (hard gate, 1 Haiku call), structural assertions (hard gate, free), usefulness rubric (soft, reported). Both seeded regressions pass; run costs ~$0.02.
  • The grader's real bug was scope, not carelessness. It was shown the excerpt first and the writing second, so it enumerated the excerpt's claims and never checked the framing at all — which is why $965B "failed" and why fabricated facts sailed through. Writing now comes first in the payload, the excerpt is labelled ground truth, and each claim must carry a verbatim span.
  • Second false positive found while labelling: the 2026-08-13 re-run flagged "~80% of Q1 dollars", which the excerpt states word for word. Seeded as a second regression case.
  • Two extras beyond the brief, both earned by a failing test: a code check that every quoted span is literally in the excerpt (a grader can invent a citation; a substring match can't), and temperature=0 on the grader — at default sampling it disagreed with itself on ~1 run in 3, which would have failed builds at random. 5/5 clean runs after.
  • Known limit, carried to Phase 8: the gate is deterministic per input, but on unseen days the grader still sometimes enumerates an inference as a claim. Fine for regression (the golden day is fixed); revisit before the grader guards live briefs — likely by moving it to a stronger model.
  • Usefulness stays ungated until calibrated against your own ratings. Judge runs on Haiku to keep spend low; upgrade it the day it starts gating.

Phase 5
Gatekeeper basics + Suppressed drawer LATER
End state: provenance + corroboration + dedup filtering, with everything killed logged to the Suppressed drawer. Also: a volume guard — the Gatekeeper caps how many items reach the Framer, and the Framer asserts loudly on item count rather than silently truncating.
Why it matters: kills noise and gives you the false-negative audit trail that keeps FOMO dead. The volume guard protects the Framer's single-call design — a 60-item day means the Gatekeeper failed, and should fail loudly rather than drop items.
~60 min
Phase 6
Daily loop end-to-end (News renders from data/) LATER
End state: a real daily brief generated Scout→Gatekeeper→Framer→News.html, with quiet-day behavior. Plus three closures found during the Phase 3 walkthrough: (1) retry loop — the Framer regenerates a flagged item and re-checks before writing, instead of flagging and shipping anyway; (2) daily smoke test — run the free structural checks on each day's output so contract violations surface immediately, not at the next prompt edit; (3) eval regenerate mode — optionally re-run the Framer on the golden input so a Framer prompt change is regression-tested, not just the grader.
Why it matters: the anti-FOMO daily value goes live — you start using it every morning. The three closures turn "flagged" into "fixed", catch drift the day it happens, and close the gap that today's harness only regression-tests the grader, never the writer.
